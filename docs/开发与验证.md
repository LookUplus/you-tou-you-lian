# 开发与验证

有头有脸使用 Swift、SwiftUI、Foundation、Contacts、SQLite 和少量 Objective-C，无第三方软件包依赖。图形版和命令行共用匹配与写入核心。

## 从源码构建

需要 Mac 和带 Swift 6 或更新版本的 Xcode / Command Line Tools，无第三方软件包依赖。

```sh
bash scripts/test.sh
bash scripts/build-app.sh
bash scripts/package-app.sh
```

App 输出在 `dist/有头有脸.app`，ZIP 与 SHA-256 校验文件输出在 `dist/release/`。同一版本重复打包时请选择新的输出目录，例如 `bash scripts/package-app.sh dist/release-new`。测试使用虚构短信、临时文件和模拟联系人，不写真实通讯录。命令行工具仍保留，见[命令行用法](命令行用法.md)。


## 验证范围

自动化测试使用虚构短信和模拟联系人，不修改真实通讯录。覆盖匹配、跨账户冲突、权限变化、重复添加、部分失败、记录恢复、撤销保护和图标外观。具体环境、已完成验证及尚未覆盖的情况见[验证说明](../验证说明.md)。

信息 App 的数据库和正文归档格式不是苹果公开稳定的应用接口，系统更新可能影响读取。保存通过系统公开接口完成，不直接修改短信或通讯录数据库。

浅色与深色图标随运行中 App 的外观选择；Finder 中的静态图标目前使用浅色版。图标由 AI 生成，素材和处理方式见 [App/Resources](../App/Resources)。

反馈和提交改动的要求见[贡献说明](../CONTRIBUTING.md)。不要提交真实短信、通讯录、计划文件、操作记录或签名证书。
