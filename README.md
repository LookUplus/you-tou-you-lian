# 有头有脸

<img src="App/Resources/AppIcon.png" width="128" alt="有头有脸图标">

让 iPhone 的企业短信有名字、有头像。这是一个在 Mac 本机运行的小工具：读取已收到短信开头的 `【品牌签名】`，匹配 vCards 黄页资料和你的现有企业联系人，核对后把 106 发件号码补进对应名片。名称和头像沿用原有资料；保存到 iCloud 账户后，由系统同步到其他设备。

**[下载 0.3.4 图形预览版](https://github.com/LookUplus/you-tou-you-lian/releases/tag/v0.3.4) · [详细使用说明](图形版使用说明.md) · [验证范围](验证说明.md)**

## 下载与使用

成品适用于 Apple 芯片 Mac，项目最低部署版本为 macOS 13；目前实际验证环境为 macOS 27.0.1，其他系统版本及 Intel Mac 尚未实测。当前是预览版，使用本地临时签名，**尚未进行 Developer ID 签名和 Apple 公证**。从网络下载后，系统可能拦截首次打开。请只使用本仓库的发布包，并先备份通讯录；已知限制见验证说明。

1. 在上面的下载页选择 `有头有脸-0.3.4-macOS-AppleSilicon-GUI.zip`，解压，把「有头有脸.app」放到固定位置（例如「应用程序」文件夹）后打开。`Source code` 是源码，不是可直接打开的 App。
2. 首次默认进入「演示数据」。点击「扫描演示数据」，核对结果，再试「模拟添加」和撤销。演示完全使用虚构资料，不读取或修改你的真实短信和通讯录。
3. 从 [metowolf/vCards 的 Releases](https://github.com/metowolf/vCards/releases/latest) 下载 `archive.zip` 并解压，或下载 `default.vcf`。先在联系人 App 中把需要的企业名片导入可编辑的账户，保留下载资料。只读的黄页订阅不能直接补号码。
4. 切换到「自己的数据」，按准备页三步操作：授权完全磁盘访问并重启 App；点击「授权并读取账户」，允许完整联系人访问后选账户；选择解压后的黄页文件夹或 `.vcf` 文件。不能直接选择 ZIP。选择资料不会自动导入联系人。
5. 点击「扫描短信」，核对「可添加」中的企业和号码，取消不需要的勾选，点击「添加」并确认。默认「自动方式」会选择适合当前系统的保存方式；系统询问是否允许控制联系人 App 时，请允许。
6. 到「操作记录」查看结果，再到联系人 App 和信息 App 核对。需要撤销时，从记录中撤销本次新增号码。

更换新版后，如果系统设置的完全磁盘访问开关已开，但检查仍失败，请重新进入权限页面刷新，移除旧条目，再添加当前这份 App；退出并重新打开后检查。联系人权限的设置按钮只打开页面，实际首次申请由「授权并读取账户」发起。详细恢复方法见[使用说明](图形版使用说明.md)。

## 能整理哪些号码

只处理已收到的 SMS 中 106 开头的发件号码。签名、黄页模板公司名和现有公司名片必须一致；允许大小写、空白和全角半角差异。简称、旗下品牌和近似名称不会自动推断归属。

- 同一号码出现多个签名、缺少签名或正文无法解析时，跳过。
- 号码已存在、被其他名片使用，或目标企业有多张同名名片时，跳过。
- 不新建联系人，不替换名称、头像或备注，不内置个人收集的名片或品牌归属规则。
- 添加需要预览和确认；撤销只移除这次新增且之后未被编辑的号码。保存部分失败时，保留记录供核对，不自动重试。

短信签名不是身份认证。匹配依据仅限这台 Mac 当前保留的历史，无法识别已经删除、未同步或未来的短信。保存名称和头像也不代表短信、链接或来电可信。

## 隐私

运行时不联网，不上传短信或通讯录，不包含分析统计服务，也不调用 AI API。此工具在 AI 协助下开发，匹配由本地规则完成。

短信数据库采用只读访问，不直接修改短信或通讯录数据库。操作记录含号码、品牌及撤销所需的电话字段，不保存短信全文或验证码；记录存放于 `~/Library/Application Support/YellowPage/Runs`，演示记录单独保存。反馈问题时请勿上传真实记录、数据库、通讯录备份或验证码。

信息 App 的数据库和正文归档格式不是苹果公开稳定的应用接口。系统更新可能影响读取；无法解析的号码会被跳过。完整验证范围和未完成项目见[验证说明](验证说明.md)。

## 从源码构建

需要 Mac 和带 Swift 6 或更新版本的 Xcode / Command Line Tools，无第三方软件包依赖。

```sh
bash scripts/test.sh
bash scripts/build-app.sh
bash scripts/package-app.sh
```

App 输出在 `dist/有头有脸.app`，ZIP 与 SHA-256 校验文件输出在 `dist/release/`。同一版本重复打包时请选择新的输出目录，例如 `bash scripts/package-app.sh dist/release-new`。测试使用虚构短信、临时文件和模拟联系人，不写真实通讯录。命令行工具仍保留，见[命令行用法](docs/命令行用法.md)。
